One line of horror — a single sentence under 200 characters — for the
[One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488)
bounty on [make.fun](https://make.fun).

## The line

> The coroner called about my father's autopsy and asked why his fingerprints matched a man buried in 1962, and the grave was empty.

130 characters. No gore, no mirror, no doll, no basement — just a phone call,
a fingerprint match, and an empty grave. The scare is what it withholds: who
was in that bed, and where is he now?

## How it works

`main.py` (Python standard library only) writes the sentence to `$ENTRY_OUT`,
whether that points at the output file itself or at the output directory
(`entry.txt` inside it). Run it with:

```sh
ENTRY_OUT=/output/entry.txt python3 main.py
```
